# Philocontext Client

React + Vite frontend for Philocontext — upload a philosophy PDF and get rich context (metadata, historical background, study guide).

## Setup

```bash
npm install
```

## Run

```bash
npm run dev
# → http://localhost:5173
```

The dev server proxies `/api` requests to the backend at `http://localhost:8000`.

## Build

```bash
npm run build
```
